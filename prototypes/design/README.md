# Design direction prototypes

Interactive phone prototypes of three candidate visual directions, published as a
design canvas: https://claude.ai/artifact/KbSBFKwLS7aVDDWDJ1UCsY

| Board | Direction |
|---|---|
| `Main.dc.html` | A · Obsidian Glass |
| `SwissMono.dc.html` | B · Swiss Mono |
| `SoftExpressive.dc.html` | C · Soft Expressive |

Each covers onboarding (instant identity), chat, file send, safety-number verify,
incoming/active call, and burn identity, with a per-direction haptic vocabulary.
All three ship as user-selectable themes (Obsidian Glass default); see `docs/design-system.md`.
